# posta (GitHub posta kutusu dalı)

Bu dal yalnızca **github** modunda kullanılır; elle düzenleme gerekmez.

- `inbox/`  — Worker'ın Telegram'dan aldığı talepler (PC okuyup siler)
- `outbox/` — PC'nin hazırladığı cevaplar (Worker Telegram'a gönderip siler)
- `cards/`  — menü kartı görselleri (içerik özetiyle adlandırılır)

Kod `main` dalındadır.
